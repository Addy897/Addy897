### Highlighted Work

- **[PTI](https://github.com/Addy897/PTI)**: P2P private set intersection for threat intel sharing. SHA-256, multi-threaded, Raylib GUI.
- **[VMObfuscate](https://github.com/Addy897/VMObfuscate)**: VM-based code obfuscator. Randomised opcode table, XOR encryption, ELF + PE support.
- **[libWeb](https://github.com/Addy897/libWeb)**: HTTP/1.1 server in C from scratch. Custom hash table, per-connection threading, cross-platform.
- **[html-renderer](https://github.com/Addy897/html-renderer)**: HTML renderer built on an 8-state tokeniser. Word-wrap, Unicode, scroll.
- **[http-cli](https://github.com/Addy897/http-cli)** — Minimalist CLI HTTP client. Handles manual socket communication, raw header serialization, and chunked transfer encoding without external networking libraries.
- **[MQTT](https://github.com/Addy897/MQTT)** — MQTT broker + client in Java. QoS 0/1, Last Will, topic routing, unit tests.
